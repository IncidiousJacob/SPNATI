Dialogue

  • Adds a Collectible (Visible) condition.

Pose Matrix

  • Adds an option to update KKL codes and convert them between KKL versions from within the CE. (Codes from KKL v105 are currently the oldest that can be converted).

Images

  • Automatically detects which images are compressed. This makes the Mark Compressed button useless, so it was removed.

Costumes

  • Allows the first layer to be a skip layer.

Miscellaneous

  • Adds support for KKL v107a7 and v108.

Bug Fixes

  • No longer automatically creates an element in the Labels list of a new costume, which was conflicting with the On Title name of the base character.
  • Fixes deleting a custom pose unassigning the pose from all lines even when a copy of the pose with the same name exists.
  • Fixes parsing of unloaded characters, which would cause the Validator to complain about their size attribute.
