Images Tab

  • Adds Smart Pose Conversion.
  • Smart Pose Conversion allows for bulk conversion of assigned dialogue poses between Poses (regular images), Custom Poses (made with the Pose Maker), and Pose Sets (made in the Pose Sets tab).

Collectibles

  • You can now select multiple images for a collectible, creating a gallery for the player to view them.
  • Adds barebones (text based) support for Hidden Exceptions, letting collectibles automatically show if events, costume sets, or specific costumes are available.

Misc. Changes

  • Allow previewing default custom poses with costume selected
