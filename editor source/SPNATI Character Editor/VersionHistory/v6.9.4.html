Costumes

  • Changes Costume Metadata
  • Costume names are now stored as a sub-element of a costume, in meta.xml. This means that newly-saved costumes will be incompatible with older Character Editor Versions.
  • Costumes can now have Descriptions that override the default character Description.
  • Costumes now have an Other Notes section.

Misc. Changes

  • Fixes an error pop-up when a collectible that had no image path set is loaded
