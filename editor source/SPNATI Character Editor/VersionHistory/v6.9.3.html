General

  • Adds support for the new optional short game mode (only one player forfeits).
  • Adds an option under the Advanced tab to allow your character to be selected in this mode.
  • Adds a condition to check for the short game mode, in the Table submenu.

Dialogue

  • Adds the ability to change the character's z-index on a per-line basis.

Pose Matrix

  • Adds a pose sheet selector button, useful if there are more pose sheets than can be displayed as tabs at once.

Pose Sets

  • Allows the creation of pose sets using images or custom poses which don't exist in the default costume.

Miscellaneous

  • Adds support for KKL v108.1.

Bug Fixes

  • Fixes a crash when renaming pose sets.
  • Fixes an issue with converting from KKL v106.
